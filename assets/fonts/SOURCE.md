# Fonts

- Rajdhani-Bold.ttf / Rajdhani-SemiBold.ttf — Rajdhani by Indian
  Type Foundry, via Google Fonts. SIL Open Font License 1.1
  (OFL.txt in this folder). Rajdhani is the recognised free
  stand-in for Cyberpunk 2077's UI typeface (Blender Pro); used
  here for Latin letters and digits only — Japanese text keeps
  M PLUS 1p. Shipped to the web build inside ModelBlob .tres
  resources under assets/font_data/ (see font_loader.gd).
